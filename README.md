# Tiya Agarwal — Portfolio

Personal portfolio site — Computer Science undergrad at VIT Vellore building full-stack and AI/ML systems: RAG platforms, AIOps dashboards, and embedded TinyML.

**Live:** [tiya-agarwal-portfolio.vercel.app](https://tiya-agarwal-portfolio.vercel.app/)

## Stack

Static site — plain HTML/CSS/JS (`index.html`), deployed on [Vercel](https://vercel.com/).

## Running locally

```bash
git clone https://github.com/tiyaagarwal/portfolio-website.git
cd portfolio-website
open index.html
```

No build step required.

## Deployment

Deploys automatically to Vercel on push to `main`.
